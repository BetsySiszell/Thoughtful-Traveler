# The No Fluff Traveler

A Quarto-based travel website focused on thoughtful travel, honest reviews, and sustainability without greenwashing.

This project was created as a final project for an R coding course using Quarto, R, CSS customization, and data visualization tools learned throughout the semester.

## Site Concept

The No Fluff Traveler explores sustainable travel through real experiences and honest reviews.

The site focuses on: - eco resorts and sustainable accommodations - outdoor and adventure travel - thoughtful tourism and environmental impact - identifying meaningful sustainability practices vs marketing claims

The goal is to combine beautiful travel storytelling with transparency and critical evaluation.

This project incorporates: - Quarto website structure - Custom CSS styling - Responsive layouts - Custom typography and branding - Image integration - ggplot2 data visualization - Multi-page website navigation - Reproducible project organization

## Rendering the Site

To render the website locally:

``` r
quarto render
```

Or use the Render button in RStudio.
